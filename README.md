Employee Attendance Analytics Dashboard

Project Description

This project is developed using Python. It displays and analyzes employee attendance records through a graphical dashboard.

Technologies Used

- Python
- Tkinter
- CSV
- Statistics

Features

- Total Employee Count
- Present Employee Count
- Absent Employee Count
- Late Employee Count
- Attendance Percentage
- Employee Details Table
- Department-wise Analysis

How to Run

1. Install Python.
2. Open the Python file.
3. Run the program.
4. The attendance dashboard will appear.

Conclusion

This project helps to manage and analyze employee attendance in a simple and effective way.
